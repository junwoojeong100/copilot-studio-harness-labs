# Label policy

## Type

- `type:bug`
- `type:feature`
- `type:docs`
- `type:question`
- `type:security`

## Priority

- `priority:P0`: active security incident, broad outage, or confirmed data loss
- `priority:P1`: severe regression without a practical workaround
- `priority:P2`: material impact with a workaround or limited scope
- `priority:P3`: minor issue, enhancement, question, or documentation

## Team

- `team:platform`
- `team:frontend`
- `team:backend`
- `team:data`
- `team:docs`
- `team:security`
- `needs-triage`

Repository reality overrides this reference: only use labels that currently exist.
